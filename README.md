# Demo Web Shop - Software Testing Portfolio
A comprehensive end-to-end software testing portfolio project built on the **Demo Web Shop** application (`https://demowebshop.tricentis.com/`). This project showcases manual test cases, API automation scripts, and database validation SQL queries.

## 🛠️ Tech Stack & Skills Demonstrated
* **Manual Testing:** End-to-end test scenarios, boundary value analysis, positive/negative test case design.
* **API Testing:** REST Assured, Java, HTTP status code validations (`200 OK`, etc.).
* **Database Testing:** SQL queries for data verification (`SELECT`, `JOIN`, `GROUP BY`, `UPDATE`, `DELETE`).
* **Test Management:** Structured test tracking using professional Excel templates.
  
## 📂 Project Files Included
1. **`PROJECT NAME DEMO WEB SHOP.txt`** - Complete manual test cases covering 8 major modules (Registration, Login, Search, Product Details, Shopping Cart, Checkout, Order History, Logout).
2. **`Api code.txt`** - REST Assured automation script in Java validating homepage API response and status codes.
3. **`DemoWebShop Database Validation.txt`** - SQL queries validating customer data, product catalogues, shopping carts, and order relationships.
4. **`DemoWebShop_Mam_Template_Filled.xlsx`** - Professional test case execution tracker with actual/expected results and statuses.
